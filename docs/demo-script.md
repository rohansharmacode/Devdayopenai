# Demo video script (target 80 seconds, hard limit 90)

**Setup.** Run `npm run reset`, then `npm start`. Open three windows:
- **Left (big):** http://localhost:3000/?as=manager
- **Right (phone-sized):** http://localhost:3000/?as=s2 (Tom). Tap **At home** before recording.
- **Spare tab:** http://localhost:3000/?as=s6 (Leo)

Set `OPENAI_API_KEY` so the badge says "Ranked by AI". Record at 1080p with notifications off, and do one dry run first.
